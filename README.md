# Java Kanban

Java Kanban — система управления задачами по методологии Kanban.

Проект позволяет создавать задачи, отслеживать их статус и управлять иерархией задач.

---

## Архитектура

Приложение написано на чистом Java:

- объектно-ориентированная модель
- менеджеры для бизнес-логики
- хранение данных в памяти / файле

---

## Функциональность

### Задачи
- создание задач
- обновление
- удаление
- изменение статуса

### Эпики
- создание эпиков
- автоматический пересчёт статуса
- управление подзадачами

### Подзадачи
- привязка к эпику
- отдельное управление

### Дополнительно
- история просмотров
- приоритет задач

---

## Технологии

- Java 21
- Collections Framework
- File I/O
- Maven

---

## Возможности

- Kanban-доска логика
- управление задачами
- иерархия задач (task/epic/subtask)
- история просмотров
- чистая OOP архитектура
